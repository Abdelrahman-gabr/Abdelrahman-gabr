## 🚀 Featured Projects

### 🔥 Real-Time Smoke & Fire Detection System
An end-to-end computer vision application designed to detect smoke and fire in images, videos, and live camera streams.

- Fine-tuned YOLO11 for smoke and fire detection.
- Applied OpenCV CLAHE preprocessing to improve visibility in low-light and hazy conditions.
- Integrated asynchronous email alerts with annotated detection snapshots.
- Built an interactive application using Streamlit.

**Tech:** Python · YOLO11 · PyTorch · OpenCV · Streamlit · SMTP

### 👓 Your Eyes — Smart Vision Assistant for Blind People
A computer vision prototype designed to help visually impaired people understand their surroundings through object detection and audio feedback.

- Real-time object detection with YOLOv8.
- Scene understanding through audio-based feedback.
- Supports live webcam input and uploaded images/videos.
- Fine-tuned a pretrained model for a custom 35-class COCO-based dataset.

**Tech:** Python · YOLOv8 · PyTorch · OpenCV · Computer Vision

### 🧠 SkillSense AI — Child Development Assessment
A computer vision project exploring automated analysis of children's drawings using the Bender test.

- Focuses on extracting visual patterns from assessment drawings.
- Explores how computer vision can support structured assessment workflows.

**Tech:** Python · Computer Vision · Image Processing · Machine Learning
